VocabFlow – نسخه قابل نصب PWA

مهم: جهت یادگیری در تمام فلش‌کارت‌ها فارسی به انگلیسی است:
روی کارت = معنی/عبارت فارسی
پشت کارت = معادل انگلیسی + تعریف + تلفظ + مترادف/متضاد + مثال + توضیح کاربرد

نصب:
1) فایل‌های این پوشه را بدون تغییر روی یک هاست استاتیک HTTPS قرار بده (مثل GitHub Pages یا هر هاست استاتیک).
2) آدرس سایت را با Chrome اندروید باز کن.
3) منوی سه‌نقطه > Install app یا Add to Home screen را بزن. آیکون VocabFlow روی صفحه اصلی می‌آید.
4) پس از اولین بارگذاری، پوسته برنامه و فایل‌های اصلی کش می‌شوند. مرور و اطلاعات ذخیره‌شده آفلاین کار می‌کنند؛ ترجمه، دیکشنری و OCR به اینترنت نیاز دارند.

قابلیت‌ها:
- پیشنهاد معادل فارسی به انگلیسی با MyMemory Translation API؛ پیشنهادها ماشینی‌اند و باید از نظر بافت بررسی شوند.
- دریافت تعریف، تلفظ نوشتاری، مترادف/متضاد و مثال‌های موجود از Free Dictionary API (dictionaryapi.dev).
- پخش تلفظ با فایل صوتی دیکشنری در صورت وجود و در غیر این صورت صدای مرورگر.
- مرور فاصله‌دار پنج‌جعبه‌ای با ارزیابی «فراموش کردم / سخت / خوب / آسان».
- سطح‌بندی CEFR، ورود CSV و XLSX، OCR تصویر فارسی و انگلیسی، خروجی و بازیابی JSON.
- داده‌ها روی همان دستگاه در localStorage ذخیره می‌شوند؛ خروجی پشتیبان بگیر.

قالب فایل:
Persian,English,Definition,IPA,Synonyms,Antonyms,Examples,Usage,Level,Notes,Image
برای چند مترادف/متضاد از کاما یا | استفاده کن. برای چند مثال از | استفاده کن.

محدودیت‌های صادقانه:
هیچ API واحدی تضمین نمی‌کند تمام واژگان A1 تا C2، همه معانی، اصطلاحات و واژگان تخصصی را بدون حذف پوشش دهد. ترجمه ماشینی ممکن است معادل نامناسب پیشنهاد دهد. دیکشنری رایگان نیز برای همه کلمات داده کامل ندارد. سطح CEFR در صورت نبود داده باید دستی تعیین شود. این اپلیکیشن ابزار مرور است و به تنهایی تضمین‌کننده آمادگی کامل IELTS/TOEFL یا هر آزمون دیگری نیست؛ برای پوشش کامل باید فهرست‌های معتبر آزمون و واژگان تخصصی را هم وارد کنی.
